## Release contract

v1.0 — это воспроизводимый baseline корпуса и Reference Implementation, а не утверждение истинности содержащихся знаний. Integrity, validation, provenance, publication, trust и recovery не превращаются в epistemic truth.

## Reproducible release surfaces

Canonical corpus остаётся в CONTENT/vertical-slices. Полный package строится существующим `build_content_package`, а offline edition — `build_offline_edition`. Release manifest и checksums должны соответствовать исходному commit.

## Recovery

Независимый disaster-recovery regression suite проверяет восстановление только из архивного package, сохранение Record identity/version и отказ при tampering или missing record.
