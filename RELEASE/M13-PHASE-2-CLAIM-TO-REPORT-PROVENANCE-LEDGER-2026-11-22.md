## 5. CSV schema and interpretation

The companion CSV has 1,501 data rows and these columns:

- `report_code` — compact identifier mapped to the exact report path in §7.
- `report_line` — 1-based source line in the report file.
- `report_row` — row position within the report's D/E/B table.
- `claim_id_at_review` — report Claim ID, with `@version` only where historical version evidence is established.
- `D`, `E`, `B` — original historical report scores, preserved without adjudication.
- `duplicate_group` — group number 1–7; blank when the row is not in one of the seven repeated groups.

Every row is `HISTORICAL_ONLY_NOT_ACCEPTED` by construction: current accepted D/E/B remains 0/1,494 and the current worksheet retains blank D/E/B / `NOT_YET_REVIEWED`. The CSV does not copy rationales; the source report line points to the complete original rationale, which remains in the source file.
