## How to read this register

This is the working content map for the first edition. It maps existing canonical vertical slices into a reader-facing order; it does not rewrite canonical records and does not claim that every listed record is approved for public release.

- **STRUCTURAL CANDIDATE** means an existing slice belongs in the proposed first-edition subject architecture.
- **RECORD SCREEN REQUIRED** means exact Claim/Evidence Use/Source/Context/Scope versions still need to be screened before any record is placed on the public allowlist.
- **HOLD** means a previously identified candidate blocker remains open.
- No slice is promoted to public INCLUDE solely because it exists or has passed CI.

The source of slice existence is the canonical `CONTENT/vertical-slices/` registry and its coverage manifest. The domain mapping below is based on existing `CONTENT/README.md`, `CONTENT/DOMAIN-ROADMAP.md`, and the current corpus registry.

### Opening section editorial rule

The sequence should move from immediate priorities to essential resources, health and protection, productive capability, hazards, and coordination. It is a navigation order, not a claim that one skill replaces another. Each practical page must distinguish:
- explanatory knowledge from action guidance;
- general principles from local emergency instructions;
- low-risk information from high-consequence procedures;
- known facts from uncertainty and missing evidence.

## Genuine cross-domain pathways

The reader experience should expose pathways such as:
- water need → water resources → hydrology → chemistry/microbiology → treatment assessment → storage → public health;
- food need → food safety/preservation → nutrition → agriculture → soil/plant biology → ecology and climate;
- shelter need → materials → mechanics → construction → settlements → infrastructure and governance;
- illness/injury → anatomy/physiology → microbiology/epidemiology → first-aid boundaries → public health;
- energy need → physics/thermodynamics → electricity → generation/storage → infrastructure → safety;
- hazard response → earth/weather/climate science → warning systems → communication → logistics → governance;
- community recovery → agriculture/production → engineering → transport/networks → economics → institutions/education.

Only create or display a pathway when the underlying Relations and source-bounded records support it. A pathway is a reader aid, not new evidence.

## Record-level selection and allowlist

The exact public allowlist remains a separate artifact. It must pin:
- record ID and version;
- record type;
- slice/domain;
- linked Claim/Evidence Use/Source identities and versions;
- Context and Scope references where applicable;
- source locator and rights/attribution state;
- consequence tier and review state;
- decision and concise reason.

Decision values:
- **INCLUDE** — exact record/version has passed the applicable publication gates.
- **HOLD** — promising or important, but one or more gates remain open.
- **EXCLUDE** — not appropriate for this edition, with a reason; may be reconsidered later.
