Date: 2026-11-18

This is a concise adoption record. Recommendations are proposed defaults, not adopted project policy. No legal, ownership, staffing, or publication decision is inferred from repository activity.

| Decision | Conservative recommendation for edition one | Current state |
|---|---|---|
| Licence for project-authored text | CC BY 4.0, only if the owner confirms attribution and downstream reuse (including commercial reuse) are acceptable; otherwise retain all rights / explicit permission until a licence is chosen | OWNER DECISION REQUIRED |
| Third-party material | No copied figures, tables, images, or substantial excerpts without item-specific permission/licence review; factual paraphrase with attribution only where legally supportable | DEFAULT PROPOSED; rights register still required |
| Accountable editor and release approver | One named human project owner/editor signs the exact allowlist and release manifest | NAME REQUIRED |
| High-consequence review | Named qualified domain reviewer; if unavailable, exclude that instructional item from edition one | REVIEWERS REQUIRED |
| Corrections and urgent takedown | One monitored public contact route; critical safety/legal/privacy/security reports trigger temporary withdrawal pending review | CONTACT + MONITOR REQUIRED |
| Contributor contact data | No hosted intake and no contact data in public payload; manual/local JSON only for first edition | RECOMMENDED DEFAULT |
| Distribution | Reproducible downloadable offline bundle first; no hosted public launch until ownership, rights, and correction operations are staffed | OWNER CONFIRMATION REQUIRED |
| Languages | Russian primary edition; translations only when reviewed and source attribution is preserved | OWNER CONFIRMATION REQUIRED |

## Release cannot be signed until
1. The project owner selects the project-authored content licence / rights model.
2. An accountable editor and release approver are named.
3. A monitored correction/takedown contact route and backup are established.
4. Exact rights/attribution checks are complete for every included record and asset.
5. High-consequence included material has qualified review; otherwise it remains outside the release.

## What can proceed without these decisions
- private reader build from a version-pinned allowlist;
- topic navigation and survival-first information architecture;
- offline reproducibility and artifact inspection;
- documentation of HOLD/EXCLUDE records and gaps;
- local/manual contribution preparation without collecting public contact data.
