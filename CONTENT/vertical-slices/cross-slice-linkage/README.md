# Cross-slice linkage

Канонические связи между уже существующими вертикальными срезами. Связи не объединяют Claims и не являются самостоятельным доказательством истины.

Состав: 13 Relation records + 1 Context record.

Связи охватывают:
- water / chemical water;
- water / filter;
- water storage / food-grade container;
- sanitation / hand hygiene;
- septic emergency / sanitation handling;
- flood food / cleanup;
- carbon monoxide / generator prevention;
- generator / home fire;
- earthquake protective action / aftershock;
- earthquake damage / protective action;
- heat / water availability;
- burn response / home fire;
- emergency lighting / home fire.

Каждая Relation указывает на уже существующие Records и сохраняет общий frame CTX-CROSS-SLICE-LINKAGE. Связь не заменяет исходные Claim, Scope или Evidence Use и не повышает их epistemic status.

Это первый слой межсрезовой сети; дальнейшее масштабирование должно добавлять только семантически обоснованные связи, а не механически увеличивать их количество.
