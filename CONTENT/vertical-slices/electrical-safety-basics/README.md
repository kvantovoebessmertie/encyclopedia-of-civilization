# electrical-safety-basics

## Назначение
Базовый образовательный срез по теме «Электробезопасность».

## Источник
https://cdc.gov/niosh/electrical-safety/about/

## Граница
Срез описывает опасности и границы компетентности; он не является инструкцией по ремонту или работе с электроустановками. Работы выполняются квалифицированными специалистами по применимым правилам.
