# administrative-law-basics

## О чём срез
Административные органы, их полномочия, процедуры контроля и обжалования.

## Граница применения
Не является инструкцией по конкретному спору с государственным органом. Полномочия, сроки и порядок обжалования зависят от юрисдикции.

## Для читателя
Для реального дела проверяйте действующие официальные правила и сроки соответствующего органа.
