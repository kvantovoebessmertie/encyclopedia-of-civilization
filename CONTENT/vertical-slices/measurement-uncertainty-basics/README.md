# measurement-uncertainty-basics

## Назначение
Неопределённость измерения количественно описывает сомнение в результате измерения.

## Источники
- NIST Technical Note 1297
- BIPM/JCGM International Vocabulary of Metrology (VIM)

## Граница
Базовый образовательный срез; утверждения ограничены указанными источниками и не являются исчерпывающим справочником.
