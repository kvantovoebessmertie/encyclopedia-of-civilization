# project-management-basics

Управление проектом включает применение знаний, навыков, инструментов и методов к деятельности проекта для выполнения его требований.

Источник: https://www.pmi.org/about/what-is-project-management

Definition of Done: source → claims → evidence use → context/scope, schema/semantic validation, publication/package/recovery regression.
