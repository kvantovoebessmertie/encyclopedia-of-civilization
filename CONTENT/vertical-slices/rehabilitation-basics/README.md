# rehabilitation-basics

P9 maturation slice. Independent evidence triangulation added for the existing 3-claim baseline.

Pattern: 2 Sources → 3 Claims → 6 Evidence Use → Context → Scope. P9 adds one independent second source and one additional Evidence Use per Claim.

Human View boundary: this slice is educational/reference information. General rehabilitation concepts must not be presented as an individualized exercise, recovery, or treatment plan. When a user describes an acute or potentially dangerous condition, the Human View must prioritize uncertainty, escalation to appropriate professional/emergency care, and verification over improvised instructions.

P9 boundary: evidence does not constitute individualized diagnosis, treatment, prescription, or other professional instruction. Specialized application requires additional context.
