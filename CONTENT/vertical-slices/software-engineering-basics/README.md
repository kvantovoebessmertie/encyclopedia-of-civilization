# software-engineering-basics

## Назначение
Вводный обзор программной инженерии через структуру общепризнанных областей знаний.

## Канонический источник
IEEE Computer Society, *SWEBOK Guide to the Software Engineering Body of Knowledge*, Version 4.0a (released September 2025).
https://ieeecs-media.computer.org/media/education/swebok/swebok-v4.pdf

Точные локаторы: Introduction to the Guide, pp. xxxvii–xli; Table I.1; Chapters 1–7.

## Граница
Руководство организует области знаний и направляет к дополнительным источникам; оно не является исчерпывающим стандартом и не предписывает одну методологию или жизненный цикл. IEEE устанавливает ограничения на коммерческое воспроизведение и перераспространение; права на производные и коллективные материалы требуют отдельной проверки.
