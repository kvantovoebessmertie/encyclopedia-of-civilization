# Вертикальный срез: холодовая безопасность и гипотермия

Девятый содержательный срез расширяет корпус в отдельный домен холодовой безопасности.

Всего: **7 Record**.

Связки:

`Source → Claim → Evidence Use`
`Claim → Context / Scope`

## Границы

Срез фиксирует только узкие положения CDC о снижении воздействия холода и распознавании гипотермии.

Не рассматриваются:

- диагностика конкретного пациента;
- индивидуальное медицинское лечение;
- расчёт времени безопасного пребывания на холоде;
- универсальные температурные пороги для всех условий;
- замена экстренной медицинской помощи.

Источник: CDC, *Safety Guidelines: During & After a Winter Storm* и *Preventing Hypothermia*.
