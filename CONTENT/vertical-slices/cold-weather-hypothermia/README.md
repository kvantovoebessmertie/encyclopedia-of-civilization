# Вертикальный срез: холодовая безопасность и гипотермия

Срез фиксирует базовые рекомендации по снижению риска гипотермии и распознаванию опасных состояний.

Всего: **10 Record**.

Связки:

`Source → Claim → Evidence Use`
`Claim → Context / Scope`

## Границы

Срез фиксирует узкие положения CDC и National Weather Service о воздействии холода, влажности и распознавании гипотермии.

Не рассматриваются:

- диагностика конкретного пациента;
- индивидуальное медицинское лечение;
- расчёт времени безопасного пребывания на холоде;
- универсальные температурные пороги для всех условий;
- замена экстренной медицинской помощи.

Источники: CDC и National Weather Service. Срез использует отдельные источники для независимой поддержки ключевых утверждений.
