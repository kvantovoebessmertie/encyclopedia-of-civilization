# quality-control-basics

Контроль процесса использует наблюдение за процессом и изменение процесса, когда данные указывают на необходимость корректирующего действия.

Источник: https://www.itl.nist.gov/div898/handbook/pmc/pmc.htm

Definition of Done: source → claims → evidence use → context/scope, schema/semantic validation, publication/package/recovery regression.
