# Базовое сохранение семян

Срез фиксирует общие рекомендации по сохранению семян. Условия хранения и сохранение жизнеспособности зависят от вида и состояния семян; универсальные параметры конкретной культуры здесь не задаются.

Evidence base: USDA + University of Minnesota Extension.

Не описывает селекцию, фитосанитарную сертификацию или профессиональную оценку конкретной культуры.
