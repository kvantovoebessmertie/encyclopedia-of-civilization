# databases-basics

## Назначение
Вводные понятия реляционной модели данных и примеры SQL на PostgreSQL.

## Канонический источник
PostgreSQL Global Development Group, *PostgreSQL 18.7 Documentation*, Part I: Tutorial, Chapter 2: The SQL Language.
https://www.postgresql.org/docs/18/tutorial.html

Точные локаторы: §§2.2–2.6 — Concepts, Creating a New Table, Populating a Table, Querying a Table, Joins Between Tables.

## Граница
Утверждения относятся к PostgreSQL 18.7 и реляционным таблицам; они не обобщаются на все модели баз данных и не заменяют документацию по администрированию, безопасности, резервному копированию и эксплуатации.
