# pharmacology-information-basics

P9 maturation slice. Independent evidence triangulation added for the existing 3-claim baseline.

Pattern: 2 Sources → 3 Claims → 6 Evidence Use → Context → Scope. P9 adds one independent second source and one additional Evidence Use per Claim.

Human View boundary: this slice is educational/reference information. It must not be rendered as individualized medication selection, dosing, substitution, interaction management, or treatment instruction. For urgent medication-related situations, the Human View must surface unknowns and direct the user to appropriate professional/emergency services rather than inventing a regimen.

P9 boundary: evidence does not constitute individualized diagnosis, treatment, prescription, or other professional instruction. Specialized application requires additional context.
