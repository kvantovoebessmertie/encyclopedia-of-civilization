# cybersecurity-basics

## Назначение
Кибербезопасность защищает информационные системы и данные от угроз для конфиденциальности, целостности и доступности.

## Источник
https://www.nist.gov/cyberframework

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
