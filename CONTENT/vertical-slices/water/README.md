# Вертикальный срез: безопасность воды при аварии

Статус: первый содержательный vertical slice.

Контур намеренно мал:

- 1 Source;
- 3 Claim;
- 3 Evidence Use.

Источником является официальный материал CDC о безопасной воде при авариях.

Этот срез не является исчерпывающей статьёй о водоподготовке. Он демонстрирует прохождение канонических Record через содержательный pipeline.

## Содержательные границы

Рассматриваются:

- микробиологическая опасность воды;
- кипячение;
- минимальная продолжительность кипячения по указанным рекомендациям;
- ограничение: кипячение не делает воду безопасной при загрязнении топливом, токсичными химическими веществами или радиоактивными материалами.

Не рассматриваются:

- универсальные схемы очистки;
- конкретные дозировки химических реагентов;
- качество воды в конкретном регионе;
- индивидуальные медицинские решения.
