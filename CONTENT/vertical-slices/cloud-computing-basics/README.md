# cloud-computing-basics

## Назначение
Облачные вычисления предоставляют вычислительные ресурсы через сетевые сервисы.

## Источник
https://www.nist.gov/publications/nist-definition-cloud-computing

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
