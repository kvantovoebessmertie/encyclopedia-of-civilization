# trigonometry-basics

## Назначение
Тригонометрия изучает отношения между углами и сторонами и связанные функции.

## Источник
https://openstax.org/books/precalculus-2e/pages/5-introduction

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
