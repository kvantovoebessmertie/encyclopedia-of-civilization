# reliability-basics

Надёжность описывает способность продукта или системы выполнять требуемую функцию в заданных условиях в течение рассматриваемого времени; она отличается от общей оценки качества.

Источник: https://www.itl.nist.gov/div898/handbook/apr/apr.htm

Definition of Done: source → claims → evidence use → context/scope, schema/semantic validation, publication/package/recovery regression.
