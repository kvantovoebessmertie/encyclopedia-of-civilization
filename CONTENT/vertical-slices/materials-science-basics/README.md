# materials-science-basics

Canonical slice: Source → Claims → Evidence Use → Context → Scope.

Sources:
- NIST — Materials Science and Engineering: https://www.nist.gov/materials-science-and-engineering
- NSF — Materials Research: https://www.nsf.gov/focus-areas/materials
- NIST — Mechanical Performance Group: https://www.nist.gov/mml/materials-science-and-engineering-division/mechanical-performance-group

Evidence boundary:
- NSF's page lists metals, ceramics, polymers and semiconductors; it does not explicitly list composites.
- NIST's Mechanical Performance Group explicitly gives composites as an example of advanced materials.
- The NIST page supports mechanical-property data, extreme operating conditions and failure analysis, but it does not fully establish an application-specific material-selection framework.
- Material classes are examples, not a mutually exclusive or exhaustive taxonomy. A class label alone does not determine suitability for a particular application.

Educational baseline; specialized application requires additional context.
