# Первая помощь при ожогах

Срез фиксирует базовые рекомендации American Red Cross и American Burn Association по первой помощи и распознаванию ситуаций, требующих срочной медицинской помощи. Не заменяет экстренную медицинскую помощь.

Всего: **12 Record**.

Связки:

`Source → Claim → Evidence Use`
`Claim → Context / Scope`

## Границы

Срез фиксирует базовые действия первой помощи и признаки серьёзных ожогов, при которых требуется медицинская помощь.

Не рассматриваются:
- индивидуальная диагностика;
- специализированное лечение ожогов;
- замена экстренной медицинской помощи.

Источники: American Red Cross, Mayo Clinic и American Burn Association. Срез использует отдельный профильный источник для независимой поддержки аварийной границы.
