# Безопасность при использовании ручного инструмента

Срез фиксирует базовые правила проверки инструмента, выбора подходящего инструмента и применения соответствующих средств защиты.

## Границы

Не является профессиональной оценкой конкретной операции, инструмента или рабочего места.

Источники: OSHA и Canadian Centre for Occupational Health and Safety (CCOHS). Срез использует независимые источники для поддержки ключевых утверждений.
