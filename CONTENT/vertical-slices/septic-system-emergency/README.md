# Аварийная септическая система

Срез фиксирует базовые документированные меры при чрезвычайной ситуации, затрагивающей септическую или локальную канализационную систему.

## Границы

Фиксируются:
- снижение необязательного использования воды;
- избегание контакта с водой, которая может быть загрязнена сточными водами;
- недопущение самостоятельной откачки при затопленном или насыщенном дренажном поле;
- необходимость профессиональной проверки при подозрении на повреждение;
- недопущение самостоятельного ремонта опасных или повреждённых систем.

Не рассматриваются инженерные расчёты, универсальные инструкции для конкретной конструкции или индивидуальная оценка безопасности.

Источники: CDC и U.S. Environmental Protection Agency (EPA).
