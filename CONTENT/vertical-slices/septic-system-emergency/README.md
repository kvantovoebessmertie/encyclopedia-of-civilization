# Вертикальный срез: аварийная септическая система

Восьмой содержательный срез расширяет корпус в отдельный домен аварийных септических и локальных канализационных систем.

Всего: **5 Record**.

Связка:

`Source → Claim → Evidence Use`
`Claim → Context / Scope`

## Границы

Срез фиксирует только общий документированный принцип снижения необязательного использования воды во время чрезвычайной ситуации, затрагивающей септическую или локальную канализационную систему.

Не рассматриваются:

- самостоятельный ремонт септических систем;
- откачка или обслуживание септика;
- инженерные расчёты;
- универсальные инструкции для конкретной конструкции;
- утверждения о безопасности конкретной системы без её оценки.

Источник: CDC, *Guidelines for Septic and Onsite Wastewater Systems*.
