# woodworking-basics

M7 focused content slice.

Profile: 3 Sources → 4 Claims → 4 claim-specific Evidence Use → Context → Scope.

## Coverage

Влажность и свойства древесины; измерение, резание, соединение и риски древесной пыли.

## Sources

- USDA Forest Products Laboratory — Wood Handbook — https://research.fs.usda.gov/fpl/wood-handbook
- University of Illinois Extension — 4-H Woodworking — https://4h.extension.illinois.edu/ways-participate/projects/woodworking
- Occupational Safety and Health Administration — Wood Dust: Hazard Recognition — https://www.osha.gov/wood-dust/hazards

## Boundary

Охвачены вводные свойства и операции. Не является проектом несущей конструкции, инструкцией по станкам или нормативом охраны труда.

## Evidence note

Each Claim has an explicit Evidence Use linked to a source. A locator alone is not treated as proof; source limitations are stated in evidence descriptions.
