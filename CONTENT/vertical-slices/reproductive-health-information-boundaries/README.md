# reproductive-health-information-boundaries

P9 maturation slice. Independent evidence triangulation added for the existing 3-claim baseline.

Pattern: 2 Sources → 3 Claims → 6 Evidence Use → Context → Scope. P9 adds one independent second source and one additional Evidence Use per Claim.

Human View boundary: this slice is educational/reference information and must preserve context, uncertainty, time and jurisdiction where relevant. It must not silently become individualized diagnosis or treatment. For urgent reproductive-health concerns, the Human View must distinguish known from unknown information and direct the user to appropriate professional/emergency care when warranted.

P9 boundary: evidence does not constitute individualized diagnosis, treatment, prescription, or other professional instruction. Specialized application requires additional context.
