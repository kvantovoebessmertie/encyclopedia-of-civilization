# distributed-systems-basics

## Назначение
Вводное определение распределённых систем, автономных вычислительных узлов и сетевого взаимодействия.

## Канонический источник
Maarten van Steen and Andrew S. Tanenbaum, “A brief introduction to distributed systems,” *Computing* 98 (2016), pp. 967–1009.
https://www.distributed-systems.net/my-data/papers/2016.computing.pdf

Точные локаторы: §1 Introduction, pp. 968–969; §2 “What is a distributed system?”, p. 969.
