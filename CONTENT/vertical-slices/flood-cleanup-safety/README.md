# Безопасность при уборке после затопления

Срез фиксирует узкие рекомендации CDC и EPA по очистке и защите при чрезвычайной ситуации с паводковой водой, включая границы безопасного повторного входа в повреждённое помещение.

Всего: **12 Record**.

Срез не является инженерной оценкой здания, электрической системы или газового оборудования и не заменяет профессиональную проверку безопасности.
