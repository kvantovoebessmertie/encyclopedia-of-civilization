# Вертикальный срез: downed-power-line-safety

Отдельный аварийный домен по электрическим опасностям после повреждения электросети.

Срез нужен для явного разделения электрической опасности от общих правил power outage, CO и flood safety. Используются существующие Record types: Source + 2 Claim + 2 Evidence Use + Context + Scope.

Источник: CDC, *What to Do to Protect Yourself From Electrical Hazards* (актуальная публикация 2026-08-26).

Граница: записи представляют документированные предупреждения и их область применимости; они не заменяют указания местной энергокомпании или экстренных служб.
