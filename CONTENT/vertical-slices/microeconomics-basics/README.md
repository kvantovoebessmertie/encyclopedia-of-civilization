# microeconomics-basics

## Назначение
Микроэкономика изучает решения отдельных участников и взаимодействие на рынках.

## Источник
https://openstax.org/details/books/principles-economics-3e

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
