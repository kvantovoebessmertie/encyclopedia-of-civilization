# social-policy-basics

## О чём срез
Социальная защита, социальные риски и меры государственной поддержки.

## Граница применения
Программы и условия различаются по странам и времени. Описание не является индивидуальной рекомендацией по пособиям или услугам.

## Для читателя
Для конкретной ситуации проверяйте официальные условия соответствующей программы.
