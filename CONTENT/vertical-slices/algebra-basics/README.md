# algebra-basics

## Назначение
Алгебра — базовый язык для записи и преобразования количественных зависимостей.

## Источник
https://openstax.org/details/books/college-algebra-2e

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.

Independent evidence: University of Minnesota Open Textbook Library Introductory Algebra. Boundary: equations and functions are mathematical objects; applying them to real systems requires an explicit model and assumptions.
