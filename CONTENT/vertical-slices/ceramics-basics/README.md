# ceramics-basics

M7 focused content slice.

Profile: 2 Sources → 4 Claims → 4 claim-specific Evidence Use → Context → Scope.

## Coverage

Глина, формование, сушка, глазурование, обжиг; кремнезёмная пыль, химические риски глазурей, печи и вентиляция.

## Sources

- Western Connecticut State University — Ceramics Health & Safety — https://www.wcsu.edu/art/health-safety/ceramics/
- Princeton University EHS — Ceramics — https://ehs.princeton.edu/health-safety-the-campus-community/art-theater-safety/art-safety/ceramics

## Boundary

Это обзор процесса и границ безопасности, не рецептура глазурей, расчёт вентиляции или замена паспортов безопасности, местных норм и испытаний.

## Evidence note

Each Claim has an explicit Evidence Use linked to a source. A locator alone is not treated as proof; source limitations are stated in evidence descriptions.
