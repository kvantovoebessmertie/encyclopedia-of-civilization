# manufacturing-basics

NIST CSRC — Manufacturing Operations: https://csrc.nist.gov/glossary/term/manufacturing_operations

The NIST definition directly covers facility operation, system processes, material inputs/outputs, maintenance, supply/distribution, health and safety, emergency response, human resources, security and information technology.
