# Вертикальный срез: emergency-alert-warning

Предметный срез по публичным аварийным оповещениям и предупреждениям.

Используются существующие Record types: Source + 2 Claim + 2 Evidence Use + Context + Scope.

Источник: FEMA IPAWS Best Practices / Tip 44 для Alerting Authorities.

Граница: записи описывают информационную функцию и структуру предупреждений; наличие alert само по себе не устанавливает истинность конкретного инцидента.
