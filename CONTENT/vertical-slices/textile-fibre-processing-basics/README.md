# textile-fibre-processing-basics

M7 focused content slice.

Profile: 2 Sources → 4 Claims → 4 claim-specific Evidence Use → Context → Scope.

## Coverage

Подготовка растительных волокон, выравнивание, прядение и скручивание; различия сырья и границы переноса методов.

## Sources

- FAO — Coir Fibre Processing — https://www.fao.org/3/y3612e/y3612e04.htm
- FAO AGRIS — The spinning and twisting of long vegetable fibres — https://agris.fao.org/search/en/providers/122535/records/65dddf9b7c7033e84be88d16

## Boundary

Охвачены подготовка растительных волокон, выравнивание, прядение и скручивание. Не охвачены синтетические волокна, химическая модификация, настройки машин и стандарты изделий.

## Evidence note

Each Claim has an explicit Evidence Use linked to a source. A locator alone is not treated as proof; source limitations are stated in evidence descriptions.
