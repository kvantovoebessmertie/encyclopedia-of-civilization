# Вертикальный срез: происхождение, авторский вклад и доверие

Седьмой срез закрывает последние три зарегистрированных типа, которые ранее были представлены только сквозными regression-тестами:

- Provenance
- Authorship Contribution
- Trust / Reputation

Всего: **7 Record**.

Связка:

`Source → Claim → Provenance`
`Source → Authorship Contribution`
`Source → Trust/Reputation signal`

Trust здесь намеренно имеет значение `not_assessed`: наличие источника, авторства или provenance не превращается автоматически в оценку истинности или доверия.
