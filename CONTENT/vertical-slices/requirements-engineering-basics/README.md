# requirements-engineering-basics

Хорошее требование формулирует, что система или ответственный субъект должен обеспечить или выполнить, а не подменяет потребность конкретным способом реализации.

Источник: https://www.nasa.gov/reference/system-engineering-handbook-appendix/

Definition of Done: source → claims → evidence use → context/scope, schema/semantic validation, publication/package/recovery regression.
