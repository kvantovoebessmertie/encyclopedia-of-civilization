# papermaking-basics

M7 focused content slice.

Profile: 2 Sources → 4 Claims → 4 claim-specific Evidence Use → Context → Scope.

## Coverage

Растительные волокна, подготовка массы, формование листа на сетке, прессование, сушка и ограничения качества.

## Sources

- Museum of Fine Arts Boston — Handmade Paper — https://www.mfa.org/programs/community-programs/art-making-at-home/handmade-paper
- Deutsches Technikmuseum Berlin — Papiertechnik — https://technikmuseum.berlin/en/program/permanent-exhibitions/translate-to-english-papiertechnik

## Boundary

Охвачены сырьё, масса, формование, прессование и сушка. Не охвачены промышленные химические режимы, пищевой контакт и архивная долговечность.

## Evidence note

Each Claim has an explicit Evidence Use linked to a source. A locator alone is not treated as proof; source limitations are stated in evidence descriptions.
