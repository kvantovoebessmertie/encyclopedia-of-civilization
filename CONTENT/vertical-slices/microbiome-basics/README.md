# microbiome-basics

## Назначение
Микробиом описывает сообщества микроорганизмов, связанных с определённой средой или организмом-хозяином.

## Источник
https://www.niehs.nih.gov/health/topics/science/microbiome

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
