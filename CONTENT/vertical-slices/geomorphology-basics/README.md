# geomorphology-basics

## Назначение
Геоморфология изучает формы рельефа и процессы, которые их создают и изменяют.

## Источник
https://apps.usgs.gov/thesaurus/thesaurus-full.php

## Граница
Базовый образовательный срез; утверждения ограничены указанным источником и не являются исчерпывающим справочником.
