Предложить материал для энциклопедии

Локальный прототип формы для экспертных предложений. Он формирует структурированный JSON-файл по контракту v1.0.

Важно: форма работает только в вашем браузере. Она ничего не отправляет и не сохраняет на сервере. После скачивания файл нужно передать редакции через отдельно утверждённый канал. Заполнение не означает принятия или публикации материала.

Не включайте сюда персональные данные, чужие закрытые материалы или полные тексты источников. Для исправления или противоречия укажите ID существующих записей. Материалы проходят редакционную и доказательную проверку.

1. Тип и тема предложения
2. Источники и доказательная база

Для каждого источника укажите не только ссылку, но и конкретный раздел, страницу, таблицу или фрагмент, который поддерживает предложение.

3. Применимость и ограничения
4. Связи с существующими записями

Для исправления нужен минимум один ID; для противоречия — минимум два.
